## 2. Заказчик 1С: что выгрузить дальше (закрывает дыры D-47)

Делает: владелец баз 1С. Передача **вне Git** (диск / SFTP / согласованный bucket). Рядом — имя файла, размер, SHA-256.

### 2.1. Сначала письменно (без выгрузки)

Ответить на три вопроса (иначе контур базы остаётся гипотезой):

1. Эта база — **центральная Розница** или **региональный узел**?
2. Платформа и имя конфигурации, как в «О программе» (не угадывать по XML 2.21).
3. Есть ли ещё рабочие базы, которые надо выгрузить тем же комплектом: центральная УТ, legacy УТ, БП?

### 2.2. Розница — полная конфигурация той же базы

Сейчас в архиве только справочники. Нужен корень выгрузки.

1. Открыть **ту же** базу в Конфигураторе.
2. Меню **Конфигурация → Выгрузить конфигурацию в файлы…**
3. Выгрузить **всю** конфигурацию в пустой каталог (не только Catalogs).
4. В корне каталога обязан появиться файл `Configuration.xml`. Если его нет — выгрузка снова неполная, не отправлять.
5. Упаковать каталог в zip. Имя: `RoznitsaXML-full-YYYYMMDD.zip`.
6. Посчитать SHA-256, передать zip + хеш. В Git не класть.

Это закрывает: релиз, подсистемы, документы, регистры, планы обмена.

### 2.3. Расширения этой базы

1. Конфигуратор → **Конфигурация → Расширения конфигурации**.
2. Каждое расширение сохранить как `*.cfe` (или выгрузить в файлы в отдельные папки).
3. Приложить список: имя расширения, назначение одной строкой, закрытый код да/нет.
4. Передать `*.cfe` вне Git.

Это CFG-001 для Розницы. 14 расширений **УТ** этим не закрываются.

### 2.4. Данные НСИ на TEST, не PROD

Нужны **элементы** справочников, не метаданные.

1. Снять копию ИБ на TEST (не выгружать боевую как есть).
2. Обезличить ФИО, телефоны, ИНН контрагентов по D-08.
3. Выгрузить **данные** (DT копии **или** XML данных) минимум по:
   - `Организации`
   - `СтруктурныеЕдиницы`
   - `Кассы`, `КассыККМ`
   - `ВидыЦен`
   - `снэксРегионы`
4. Написать, какой элемент считать контрольным магазином (код/GUID после выгрузки).

Без этого GUID точек в MDM не заполняются. AP-203 **не** наполнять с потолка.

### 2.5. Тот же комплект для УТ и БП

Повторить 2.2–2.4 для:

| База | Минимум |
|---|---|
| Центральная УТ | CF или полный XML + список расширений (ожидается порядка 14) + обезличенный срез организаций/складов |
| Legacy УТ | хотя бы релиз и факт, что база ещё жива |
| БП | релиз + план обмена с УТ |

Цепочка G1: Розница → УТ → БП. Одного розничного Catalogs недостаточно.

### 2.6. Чего не делать с файлами

- не коммитить zip / xml / dt / cf / cfe в Git;
- не грузить полученные файлы в PROD;
- не считать этот частичный ZIP «выгрузкой базы»;
- не выключать Frontol и расширения «заодно».
