# Пообъектные индексы расширений

Шесть JSON из XML-выгрузок расширений. В Git: имена объектов, UUID, синонимы, реквизиты, `procedureCount`. **Нет** массива имён процедур и нет тел BSL.

Полные конфигурации Розницы и УТ проиндексированы компактно на уровень выше: `../retail-config-index.json`, `../ut-config-index.json` (имена объектов из `Configuration.xml`, детальные UUID только для справочников/документов/планов обмена/регистров сведений). Полный пообъектный дамп всех 17k объектов в Git не кладётся.

MCP `snax-1c` читает оба слоя: компактные индексы конфигураций и эти пообъектные JSON расширений.
