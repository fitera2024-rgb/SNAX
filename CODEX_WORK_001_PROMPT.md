## Важное правило Codex Cloud

В изолированном checkout Codex Cloud локальная ветка может называться `work`, `git remote -v` может быть пустым, `gh` может быть не авторизован, а прямой `git fetch` может быть запрещён. Это штатный режим.

**Не блокируй реализацию из-за:**

- локального имени ветки `work`;
- отсутствия remote;
- отсутствия `gh auth`;
- невозможности открыть существующий PR shell-командой;
- невозможности выполнить `git fetch` из sandbox.

Работай в текущем checkout. Публикация выполняется встроенным действием Codex Cloud после завершения кода.
