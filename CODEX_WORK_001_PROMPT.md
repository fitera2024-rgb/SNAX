## Выполни

Создай воспроизводимый monorepo baseline внешнего сервиса:

- Python 3.12+ / FastAPI API с `/health` и `/version`;
- React + TypeScript + Vite web-интерфейс;
- Docker Compose с PostgreSQL, Redis и MinIO;
- backend/frontend tests и quality gates;
- GitHub Actions CI;
- русский web shell в стиле SNAX;
- маршруты `/`, `/imports`, `/imports/new`, `/imports/:id`, `/profiles`, `/settings`;
- mock-data, без реального parsing и без коммерческих файлов;
- актуальный README с реально проверенными командами.

## UI

Интерфейс должен быть деловым и компактным:

- глубокий сине-графитовый sidebar;
- бирюзовый акцент;
- светлая рабочая область;
- белые карточки;
- компактные таблицы и status badges;
- без градиентов;
- desktop-first, но корректно на 390 px;
- русские тексты.

## Использование Spark

После создания и проверки основного каркаса можно передать **GPT-5.3-Codex-Spark** отдельную узкую подзадачу только на визуальную полировку конкретных компонентов. В такой подзадаче перечисли точные файлы и обязательно потребуй выполнить `lint`, `typecheck`, component tests и `build`. Spark не должен менять зависимости, CI, контракты или структуру проекта.
